# WCS JetEngine Skeleton Loader

![Обложка WCS JetEngine Skeleton Loader](assets/release-cover.png)

Небольшой WordPress-плагин для Elementor и JetEngine. Он заменяет стандартный спиннер JetEngine на аккуратные карточки-скелетоны, пока Listing Grid загружается асинхронно.

> Неофициальное расширение. Оно не связано с Crocoblock и не изменяет файлы JetEngine.

## Что умеет

- Включается отдельно у каждого виджета **Listing Grid**.
- Работает с родной опцией JetEngine **Lazy load**.
- Скрывает бесполезный круговой индикатор JetEngine только для включённого листинга.
- Формирует две строки скелетонов по числу фактических колонок сетки, максимум 12 карточек.
- Учитывает desktop, tablet и mobile‑брейкпоинты Elementor.
- Для **Scroll Slider** на планшете и телефоне показывает горизонтальные карточки с той же шириной и промежутком, что и будущие карточки листинга.
- После первой загрузки запоминает пропорции реальных карточек для текущего листинга и брейкпоинта, чтобы последующие скелетоны занимали более точное место.
- Поддерживает Carousel и подключённые запросы JetSmartFilters (включается отдельным переключателем).
- Уважает `prefers-reduced-motion`.

## Требования

- WordPress 6.0+
- PHP 7.2+
- Elementor
- JetEngine

JetSmartFilters нужен только для отображения скелетона во время фильтрации.

## Установка

1. Скачайте `wcs-jetengine-skeleton-loader-1.0.0.zip` из [Releases](../../releases).
2. В WordPress откройте «Плагины → Добавить новый → Загрузить плагин» и активируйте его.
3. Откройте страницу в Elementor, выберите **Listing Grid**.
4. Включите родную опцию **Lazy load**.
5. В конце блока настроек включите **«Скелетон-загрузчик»**.
6. Если у листинга есть связанный JetSmartFilters, при необходимости включите **«Показывать при фильтрации JetSmartFilters»**.

Плагин при активации сам создаёт один MU‑загрузчик в `wp-content/mu-plugins`. Он нужен только потому, что JetEngine регистрирует настройки Elementor раньше обычных плагинов. MU‑файл имеет фиксированное имя, создаётся из файлов плагина, проверяется по внутренней метке и удаляется при деактивации либо полном удалении плагина.

Если WordPress не может записать в `wp-content/mu-plugins`, появится уведомление администратора. Дайте этой папке права на запись и заново активируйте плагин.

## Как рассчитывается скелетон

Обычная сетка: число карточек = текущие видимые колонки × 2. Сначала скрипт читает реальные CSS‑колонки на экране, затем использует настройки Listing Grid как резервный вариант.

Для Scroll Slider скелетон показывает три горизонтальные карточки. Их ширина и зазор берутся из `Static column width` и `Horizontal gap` соответствующего устройства. Поэтому на телефоне место резервируется под будущий ряд, а не под вертикальный список.

После появления реальных карточек плагин измеряет их максимальную высоту и ширину, сохраняет только пропорцию в памяти браузера для текущей вкладки и применяет её к следующему скелетону. Никакие данные посетителя, содержимое карточек или настройки сайта не сохраняются. При первом открытии страницы используется обычный шаблон, а после загрузки пропорция уточняется автоматически.

## Проверка

После включения откройте страницу в приватном окне или с отключённым кэшем. Во время загрузки должны появиться скелетоны, затем — реальные карточки без прыжка сетки. Проверьте desktop и mobile, а для связанного фильтра — запрос JetSmartFilters.

## Разработка

В архив установки входит только папка `wcs-jetengine-skeleton-loader`. Исходники распространяются по лицензии GPL-2.0-or-later.

## Обновления

Плагин проверяет манифест обновлений на сервере WCS по HTTPS. Новые версии публикуются GitHub Actions только после создания тега вида `vX.Y.Z`; номер тега обязан совпадать с версией в заголовке главного PHP-файла. Workflow собирает ZIP, создаёт GitHub Release и размещает ZIP вместе с `metadata.json` на сервере обновлений.
